# MathGao 组卷题面美化

为组卷网数学题设计的 Chrome 扩展。调整题目字体、公式比例和背景颜色，将单题整理成干净题面，方便手动截图后粘贴到 OneNote 讲课。

## 下载与安装

从 [最新发布版本](https://github.com/erniaodoudoufei/mathgao-zujuan/releases/latest) 下载 `MathGao-Zujuan-1.1.0.zip`，完整解压到固定文件夹。

1. 在 Chrome 地址栏打开 `chrome://extensions`。
2. 打开右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择解压后的 `extension` 文件夹。
4. 刷新已经打开的组卷网页面。

也可以下载或克隆本仓库，直接加载其中的 `extension` 文件夹，无需编译。安装后请保留该文件夹。更新时替换文件，点击扩展管理页的“重新加载”，再刷新组卷网页面。

## 功能

- **原页美化**：支持单题详情和多题列表，动态出现的新题自动应用排版。
- **单题展示**：保留题干、选项、公式、表格和题图，排除答案解析及网站操作栏；支持隐藏工具栏和按 Esc 退出。
- **5种字体**：思源黑体、微软雅黑、思源宋体、宋体、楷体，按本机字体情况自动回退。
- **6套背景**：纯白、浅草绿、暖米黄、淡雾蓝、柔雾灰、浅藕粉。
- **4种文字颜色**：墨黑、深灰绿、藏蓝、深棕。
- **排版调整**：字号16–32px、行距1.4–2.2、单题宽度640–1200px，设置自动保存在本机。

默认使用22px字号、1.8倍行距、960px题面宽度。可以先试“思源黑体＋浅草绿＋墨黑”。点击题目旁的“单题展示”，调整外观并隐藏工具栏，再用截图软件框选题面，切换 OneNote 按 Ctrl+V。

详细操作见 [安装说明](安装说明.md)。

## 权限与显示范围

采用 Manifest V3，仅在 `https://zujuan.xkw.com/*` 运行，只申请 `storage` 权限保存设置。无需额外账号和服务器，不增加遥测或外部 API，题图继续从网站原有资源地址加载。

这是独立开发的非官方扩展。它只调整网页显示：公式保留原图字形和颜色，扫描题图中的文字不能单独换字体；长题仍需手动分段截图。本版本不包含一键截图、OCR、答案提取或自动写入 OneNote。

## 开发与检查

无需安装 npm 依赖。使用 Node.js 运行设置测试：

```shell
node --test tests/settings.test.cjs
node --check extension/content.js
node --check extension/popup.js
node --check extension/settings.js
```

浏览器回归使用合成题目和测试存储替身，不需要登录组卷网：

```shell
python -m http.server 8765 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8765/tests/fixture.html`，等待约一分钟，查看36项检查的结果。测试覆盖公式缩放与恢复、上下标、选项与图表、动态题目、字体背景、设置保存和展示窗口交互。测试替身不会包含在安装包内。

## 打包

```shell
python scripts/package.py
```

脚本从 manifest 读取版本，在 `dist/` 生成 ZIP 和 SHA-256 校验文件。ZIP 只包含扩展、README 和安装说明。
